## 关于这个仓库

暑假的最后几天，我突然想到这个事，决定再做一次这个题目，于是有了这个仓库

使用 Rust 实现的简单 JPEG 编码器，输入和 RGB Raw 格式的图片，输出编码后的 JPEG 图片  
采用的 Rust 版本是 2024，rustc 版本是 `rustc 1.98.0 (88d9e12ae 2026-08-18)`
