# What-is-JPEG Solve

这是一个很老的题目的解答，正好是四年前我刚上大学的时候的社团招新的题目，题目详细说明在[这里](./docs/what-is-jpeg.md)  
题目是把 `example` 目录下面的 raw 格式图片 `demo.bin`，压缩为一个 `demo.jpg`，需要自己实现编码器，不能复用已有的图像编码库  
当时真的很嫩，啥也不会，最后输出的时候都不知道用 `wb`，折腾了一个礼拜，硬是用字符输出了一大堆 010001001001... :X，人家都没法检查对不对，不了了之了

不过现在再看就简单多了

## 关于这个仓库

使用 Rust 实现的简单 JPEG 编码器，输入和 `demo.bin` 相同格式的 RGB Raw 图片，输出 jpeg 图片  
采用的 Rust 版本是 2024，要求编码库能导出 C 接口，同时支持 no_std 编译

另外为了和当时体验相仿，不能使用 AI 辅助编码
